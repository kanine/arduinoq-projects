Buzzer Control

Wiring Requirements

Connect a DFR0032 Digital Buzzer Module to the Arduino UNO Q using 3 jumper wires:

Board PinModule PinNotes
D8S (Signal)HIGH = buzzer ON, LOW = OFF
3.3 VVCC3.3 V compatible
GNDGND–

The DFR0032 has a built-in NPN transistor driver — no current-limiting resistor is needed. All UNO Q GPIO pins operate at 3.3 V.
